Developed an AI-powered Mental Health Chatbot built using Large Language Models (Gemini LLM) and Retrieval-Augmented Generation (RAG). It provides context-aware and empathetic responses by retrieving relevant mental health information from a custom knowledge base. The system uses embeddings and FAISS for efficient semantic search and integrates transformer-based models for natural conversation. The chatbot is designed to deliver informative, supportive, and personalised interactions while demonstrating practical applications of RAG in healthcare AI.
